# Tileserver OSM Airgap

Docker Compose stack for serving air-gapped OpenStreetMap vector MBTiles and raster MBTiles with TileServer GL. It includes Planetiler-based vector generation from an existing `.osm.pbf`, local OpenMapTiles-compatible styles, and a MapLibre viewer that combines a vector base map with multiple raster overlays.

## Quick Start

```powershell
Copy-Item .env.example .env
.\scripts\vendor-assets.ps1
.\scripts\generate-demo-raster-mbtiles.ps1

# Put your PBF at data/input/source.osm.pbf, then generate vector MBTiles:
.\scripts\generate-vector-mbtiles.ps1 -Pbf data/input/source.osm.pbf -Output data/mbtiles/osm-vector.mbtiles

docker compose up -d tileserver viewer
```

Open:

- TileServer GL: http://localhost:8080
- Combined MapLibre viewer: http://localhost:8081

## Data Layout

```text
data/
  input/       # source .osm.pbf files, ignored by Git
  mbtiles/     # generated vector and raster .mbtiles, ignored by Git
tileserver/
  config.json
  styles/
  fonts/       # generated by vendor-assets
  sprites/     # generated by vendor-assets
viewer/
  index.html
  layers.json
  vendor/      # generated by vendor-assets
```

## Main Commands

```powershell
# Download MapLibre, styles, sprites, and fonts for offline use
.\scripts\vendor-assets.ps1

# Generate synthetic raster MBTiles used by the demo viewer
.\scripts\generate-demo-raster-mbtiles.ps1

# Generate vector MBTiles from an existing PBF
.\scripts\generate-vector-mbtiles.ps1 -Pbf data/input/source.osm.pbf

# Prepare a transferable offline bundle
.\scripts\prepare-online-bundle.ps1

# On the offline host
.\scripts\load-airgap-bundle.ps1
```
